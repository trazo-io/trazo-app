Batch S3 Images Test

Open the console and check:

  1. Console logs - Look for 🚀 🔍 📡 emojis
  2. Network tab - Look for get-presigned-read-urls-batch requests
  3. Window debug - Type window.__TRAZO_BATCH_DEBUG in console

What to Look For:

✅ Success Signs:

  • 📡 [useBatchS3Images] Triggering batch query for URLs
  • Network request to /api/get-presigned-read-urls-batch/
  • window.__TRAZO_BATCH_DEBUG.batchTriggered === true

❌ Problem Signs:

  • 🔥 [S3Image] FALLBACK: Making individual presigned URL request
  • Network requests to /api/get-presigned-read-url/ (singular)
  • window.__TRAZO_BATCH_DEBUG.batchTriggered === false

Quick Debug Commands:

// Check if batch was triggered
window.__TRAZO_BATCH_DEBUG

// Clear debug info
delete window.__TRAZO_BATCH_DEBUG

// Manual check
console.log("Debug info:", window.__TRAZO_BATCH_DEBUG)
